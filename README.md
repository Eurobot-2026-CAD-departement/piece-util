# Piece util

Library of CAD for **commonly used parts**, so you do not have to remodel them: motors, wheels, servos, pulleys, rails, sensors and more.

## Examples of what you will find
- **Motors & wheels** — Pololu motors, JGB37-520 geared motor + bracket, JSUMO wheel rim/tyre, encoder + support, encoder wheel
- **Servos** — MG996R, ONYX S45 (with arms), TIANKONGRC 30 KG
- **Motion** — GT2 16T pulley, aluminum pulley, ball screw, MGN12 guiding rail + support
- **Pneumatics** — miniature piston pump
- **Electronics** — IMU cover, Raspberry Pi parts
- **Game elements** — crates (`4 crates`, colored)

Most folders are `.snapshot` downloads from vendor/CAD libraries containing the STEP/SolidWorks files and datasheets.
